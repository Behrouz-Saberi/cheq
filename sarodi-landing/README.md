# لندینگ کلید هوشمند سارودی (پلاگین وردپرس)

لندینگ سه‌بعدی و تعاملی برای کلیدهای هوشمند لمسی سارودی. فقط HTML/CSS/JS خام است (بدون build) و همهٔ فایل‌ها، از جمله Three.js و فونت Vazirmatn، روی هاست خودتان قرار می‌گیرند. به هیچ CDN خارجی وابسته نیست و با فیلترینگ مشکلی ندارد.

## نصب روی وردپرس
1. فایل `sarodi-landing.zip` را از «افزونه‌ها ← افزودن ← بارگذاری» نصب و فعال کنید.
2. یکی از این دو روش:
   - **تمام‌صفحه (پیشنهادی):** یک برگهٔ جدید بسازید و در «ویژگی‌های برگه ← قالب»، گزینهٔ «Sarodi Landing (تمام‌صفحه)» را انتخاب کنید. هدر و فوتر قالب حذف می‌شود ولی `wp_head` (Rank Math/Yoast، آنالیتیکس) سر جایش می‌ماند.
   - **داخل قالب یا المنتور:** شورت‌کد را در ویجت Shortcode بگذارید:
     `[sarodi_landing cta="https://imenabco.com/contact" tel="tel:03133120"]`
3. اگر WP Rocket، LiteSpeed یا Autoptimize دارید، پوشهٔ `sarodi-landing/assets/js/` باید از combine/defer/delay مستثنا باشد. پلاگین این کار را خودکار انجام می‌دهد؛ اگر دمو کار نکرد، دستی هم چک کنید (اسکریپت‌ها ES module هستند).

## پارامترهای شورت‌کد
| پارامتر | پیش‌فرض | کاربرد |
|---|---|---|
| `cta` | `#slp-contact` | لینک همهٔ دکمه‌های «استعلام قیمت» |
| `tel` | `tel:03133120` | لینک تماس |

## ساختار
- `templates/landing.html`: کل markup (متن‌ها را همین‌جا ویرایش کنید)
- `assets/js/panels.js`: وکتور دقیق آیکن‌ها که یک‌به‌یک از فایل CDR استخراج شده
- `assets/js/hero3d.js`: مدل سه‌بعدی محصول (نمای انفجاری، پشت محصول و لیبل، تغییر مدل)
- `assets/js/room3d.js`: اتاق سه‌بعدی دمو (چراغ‌ها، پرده، کولر)
- `assets/js/store.js`: وضعیت مشترک؛ پنل، اتاق، مدل سه‌بعدی و اپ با هم هم‌گام هستند
- `index.html`: پیش‌نمایش مستقل (`python3 build-preview.py` آن را از قالب می‌سازد)

## پیش‌نمایش محلی
```
cd sarodi-landing && python3 -m http.server 8000
# http://localhost:8000
```

## نکات
- لمس روی موبایل: هدف لمس در لحظهٔ `pointerdown` و از روی همان ژست مدل محاسبه می‌شود، و مدل تا ۵ ثانیه ثابت می‌ماند. ناحیهٔ لمس هر پل کل سهم آن پل از پنل است (یک‌سوم، نصف یا یک‌چهارم)، نه فقط آیکن.
- `prefers-reduced-motion` رعایت می‌شود. اگر WebGL در دسترس نباشد، نسخهٔ SVG ثابت نمایش داده می‌شود.
- اسکیما `Product` و `FAQPage` داخل قالب قرار دارد.
- کلیک روی CTAها رویداد `sarodi_cta` را به `dataLayer` (GTM/GA4) می‌فرستد.
