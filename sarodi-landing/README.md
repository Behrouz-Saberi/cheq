# لندینگ کلید هوشمند سارودی (پلاگین وردپرس)

لندینگ سه‌بعدی و تعاملی برای کلیدهای هوشمند لمسی سارودی. روی هاست به هیچ build یا Node نیاز ندارد و همهٔ فایل‌ها، از جمله Three.js و فونت Vazirmatn، روی هاست خودتان قرار می‌گیرند. به هیچ CDN خارجی وابسته نیست و با فیلترینگ مشکلی ندارد.

## فایل‌های آمادهٔ بارگذاری (پوشهٔ `release/`)
| فایل | کاربرد |
|---|---|
| `sarodi-landing-wp-plugin.zip` | پلاگین وردپرس (پیشنهادی برای imenabco.com) |
| `sarodi-landing-static.zip` | سایت استاتیک؛ در هر هاستی داخل یک پوشه (مثلاً `public_html/smart`) اکسترکت شود |
| `sarodi-landing-single.html` | یک فایل مستقل که همه‌چیز داخل خودش است؛ کافی است آپلود شود |

## نصب روی وردپرس
1. از «افزونه‌ها ← افزودن ← بارگذاری افزونه»، فایل `sarodi-landing-wp-plugin.zip` را نصب و فعال کنید.
2. یکی از این دو روش:
   - **تمام‌صفحه (پیشنهادی):** یک برگهٔ جدید بسازید و در «ویژگی‌های برگه ← قالب»، گزینهٔ «Sarodi Landing (تمام‌صفحه)» را انتخاب کنید. هدر و فوتر قالب حذف می‌شود ولی `wp_head` (Rank Math/Yoast، آنالیتیکس) سر جایش می‌ماند.
   - **داخل قالب یا المنتور:** شورت‌کد `[sarodi_landing cta="https://imenabco.com/contact"]` را در ویجت Shortcode بگذارید. لندینگ به‌صورت خودکار تمام‌عرض می‌شود و هدر قالب به‌جای منوی لندینگ استفاده می‌شود (با `nav="1"` منوی خود لندینگ هم نمایش داده می‌شود).
3. اگر کش یا بهینه‌ساز دارید (WP Rocket، LiteSpeed، Autoptimize)، پس از نصب کش را پاک کنید. فایل `sarodi.bundle.js` به‌صورت خودکار از delay/combine مستثنا می‌شود.

## پارامترهای شورت‌کد
| پارامتر | پیش‌فرض | کاربرد |
|---|---|---|
| `cta` | `#slp-contact` | لینک همهٔ دکمه‌های «استعلام قیمت» |
| `tel` | `tel:03133120` | لینک تماس |
| `nav` | `0` | داخل قالب: `1` یعنی منوی خود لندینگ هم نمایش داده شود |

## ساختار و ویرایش
- `templates/landing.html`: کل markup و متن‌ها (برای تغییر متن فقط همین فایل را ویرایش کنید)
- `assets/css/landing.css`: استایل‌ها
- `src/js/`: سورس جاوااسکریپت (`hero3d.js` مدل سه‌بعدی، `room3d.js` اتاق دمو، `motion.js` اسکرول نرم و انیمیشن‌های GSAP، `store.js` وضعیت مشترک، `panels.js` وکتور آیکن‌ها که از فایل CDR استخراج شده)
- `assets/js/sarodi.bundle.js`: خروجی build. بعد از تغییر در `src/js/` از ریشهٔ ریپو این دستورها را اجرا کنید: `npm i && npm run build`. این دستور هر سه بستهٔ `release/` را دوباره می‌سازد.

## پیش‌نمایش محلی
```
cd sarodi-landing && python3 -m http.server 8000
# http://localhost:8000
```

## نکات
- لمس روی موبایل: هدف لمس در لحظهٔ `pointerdown` و از روی همان ژست مدل محاسبه می‌شود، و مدل تا ۵ ثانیه ثابت می‌ماند. ناحیهٔ لمس هر پل کل سهم آن پل از پنل است (یک‌سوم، نصف یا یک‌چهارم)، نه فقط آیکن.
- `prefers-reduced-motion` رعایت می‌شود. اگر WebGL در دسترس نباشد، نسخهٔ SVG ثابت نمایش داده می‌شود.
- اسکیما `Product` و `FAQPage` داخل قالب قرار دارد.
- کلیک روی CTAها رویداد `sarodi_cta` را به `dataLayer` (GTM/GA4) می‌فرستد.
